# particle-network

![Animation](https://miro.medium.com/max/1400/1*a4tiXdRcOxYEQn-SyV6Jcw.png)

Particles drift across a full-screen canvas, and a line links each pair closer than the link distance. Lines fade as their particles move apart, and the triangles they form can be filled. The pointer can attract, repel or swirl particles. Press `h` or the button in the top-right corner to open the controls.

Live demo available [here](https://particle-network-live.vercel.app/)

## Install

```sh
pnpm install
```

## Develop

```sh
pnpm dev
```

## Build

```sh
pnpm build
```
